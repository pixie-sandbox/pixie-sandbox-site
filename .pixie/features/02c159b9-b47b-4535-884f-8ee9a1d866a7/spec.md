## What was asked for

Add an accessibility 'skip to content' link to the Pixie sandbox Next.js site. This link will be visually hidden by default to avoid cluttering the UI for mouse users, but will become visible when a keyboard user tabs into it. Clicking the link will move the system focus to the primary content area of the page, allowing keyboard and screen reader users to bypass repetitive header navigation.

## Acceptance criteria

- **AC1** — given A user is navigating the site via keyboard, when the user presses the Tab key for the first time after a page load, then the skip-to-content link becomes visually visible on the screen
- **AC2** — given The skip-to-content link is visible and focused, when the user presses Enter or Space, then the browser focus shifts to the main content area
- **AC3** — given A user is navigating with a mouse, when the user views the page, then the skip-to-content link is not visible

## Where this was expected to land (the Architect's sketch)

- `app/layout.tsx` — Insert the SkipLink component as the first child of the <body> element to ensure it is the first focusable element.
- `components/SkipLink.tsx` — A new component that renders an anchor link with styles to be visually hidden (using Tailwind's 'sr-only' pattern) but visible on focus.
- `app/page.tsx` — Add 'id="main-content"' to the <main> element to provide a target for the skip link.
- `app/changelog/page.tsx` — Add 'id="main-content"' to the <main> element to provide a target for the skip link.
