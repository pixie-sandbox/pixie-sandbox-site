## Outcome

Users can see the total number of changelog entries at a glance on the changelog page.

## What was asked for

The Pixie sandbox changelog page will display the total count of all entries found in the `changelog.json` data source. This count will appear directly beneath the main page heading, styled with muted text, and will use correct singular/plural grammar (e.g., '1 entry' vs '42 entries').

## Acceptance criteria

- **AC1** — given the changelog.json file contains 42 entries, when a user visits the changelog page, then the system displays '42 entries' in muted text directly under the page heading
- **AC2** — given the changelog.json file contains 1 entry, when a user visits the changelog page, then the system displays '1 entry' in muted text directly under the page heading
- **AC3** — given the changelog.json file contains 0 entries, when a user visits the changelog page, then the system displays '0 entries' in muted text directly under the page heading

## Components the Architect expected to change

- `app/changelog/page.tsx` (modify) — Calculate the total number of entries from the imported changelog JSON and render the count text below the main heading.
