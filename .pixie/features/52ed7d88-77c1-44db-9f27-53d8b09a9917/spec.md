## Outcome

Every deployed build of the site shows its build date in the footer, making it immediately obvious which version is running without opening CI logs.

## What was asked for

Add a 'Built: YYYY-MM-DD' line to the site footer, showing the date the site was last built. The date is injected at build time via the NEXT_PUBLIC_BUILD_DATE environment variable. When the variable is absent (local development), the line is not rendered.

## Acceptance criteria

- **AC1** — given NEXT_PUBLIC_BUILD_DATE is set to '2026-10-17' at build time, when a visitor loads any page containing the footer, then the footer contains the text 'Built: 2026-10-17'
- **AC2** — given NEXT_PUBLIC_BUILD_DATE is not set, when the footer renders, then no element matching 'Built:' is present in the footer
- **AC3** — given the footer is rendered with a build date present, when the page is inspected visually and via DevTools, then the 'Built:' line uses the same text size and muted zinc colour as the 'Last updated' line immediately above it — a person checks this before merging: Compare the 'Built:' paragraph against the 'Last updated' paragraph — both should share text-sm and the zinc-600 / dark:zinc-400 colour pair; no test is needed

## Where this was expected to land

- `components/Footer.tsx` — Add the conditional 'Built: YYYY-MM-DD' paragraph below the existing 'Last updated' paragraph.
- `__tests__/Footer.test.tsx` — Existing footer test file; new AC1/AC2 tests added alongside existing ones.
