## Outcome

Visitors can view a history of site updates on a dedicated page and subscribe to updates via an RSS feed.

## What was asked for

A new /changelog page and /changelog.xml RSS feed for the sandbox site. The page will list site updates in reverse chronological order, using a local data file for content. Each entry consists of a title, a single block of descriptive text, and a relative timestamp (e.g., '3 days ago') that reveals the full date via a styled UI tooltip on hover. The RSS feed will use standard RFC 822/ISO 8601 timestamps. The UI will match the existing site's zinc-based theme and support both light and dark modes.

## Acceptance criteria

- **AC1** — given A user navigates to /changelog, when the page loads, then they see a list of site updates ordered by newest first, matching the site's design system.
- **AC2** — given An entry has a relative date (e.g., '5 minutes ago'), when the user hovers over the date, then a styled UI tooltip appears showing the exact timestamp.
- **AC3** — given A user or feed reader accesses /changelog.xml, when the XML is parsed, then it contains the correct entry titles, descriptions, and standard ISO 8601 timestamps.
- **AC4** — given The site is in dark mode, when the user views the /changelog page, then the colors and typography match the existing dark mode theme tokens.

## Components the Architect expected to change

- `data/changelog.json` (new) — Local JSON file containing changelog entries (title, description, date).
- `app/changelog/page.tsx` (new) — Main page route for the changelog.
- `app/changelog.xml/route.ts` (new) — Next.js Route Handler to generate the RSS feed XML.
- `components/changelog/ChangelogList.tsx` (new) — Container component for rendering the list of entries.
- `components/changelog/ChangelogEntry.tsx` (new) — Displays an individual entry with relative date and tooltip.
- `components/ui/Tooltip.tsx` (new) — A simple, accessible tooltip component for displaying absolute timestamps.
