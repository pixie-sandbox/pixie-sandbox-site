## Outcome

Users can see the current year and easily access the project's GitHub repository from a centered footer on every page.

## What was asked for

Update the existing site footer to include a link to the GitHub repository. The footer will display the current year and a GitHub icon accompanied by a link, all centered on the page. The styling will follow the existing Tailwind CSS patterns and ensure readability in both light and dark themes.

## Acceptance criteria

- **AC1** — given a user is on any page of the sandbox site, when they scroll to the bottom of the page, then they see a centered footer containing the current year and a GitHub icon/link
- **AC2** — given the site is in light mode, when the footer is viewed, then the year and GitHub link are clearly readable
- **AC3** — given the site is in dark mode, when the footer is viewed, then the year and GitHub link are clearly readable
- **AC4** — given the user clicks the GitHub link in the footer, when the link is activated, then the user is navigated to https://github.com/pixie-sandbox/pixie-sandbox-site

## Where this was expected to land (the Architect's sketch)

- `components/Footer.tsx` — Update the footer to include a GitHub icon (inline SVG) and a link to the repository. Ensure the year is dynamic (already exists) and everything is centered.
