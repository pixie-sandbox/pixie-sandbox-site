## What was asked for

Add a global footer component to the Pixie sandbox Next.js site. The footer will display the current year and a link to the project's GitHub repository. It must be integrated into the root layout so that it is visible on every page, adheres to the existing Tailwind CSS design system, and supports both light and dark modes.

## Acceptance criteria

- **AC1** — given A user is on any page of the sandbox site, when They scroll to the bottom of the page, then They see a footer containing the current year and a GitHub link.
- **AC2** — given The site is in light mode, when The footer is visible, then The text and link colors are legible and match the site's light theme palette.
- **AC3** — given The site is in dark mode, when The footer is visible, then The text and link colors are legible and match the site's dark theme palette.
- **AC4** — given The user clicks the GitHub link, when The link is activated, then The GitHub repository page opens in a new tab.

## Components the Architect expected to change

- `components/Footer.tsx` (new) — A new stateless component that displays the current year and a link to the GitHub repository. It will use Tailwind CSS for theming support.
- `app/layout.tsx` (modify) — Import and include the `<Footer />` component within the `<body>` tag. The body already uses `flex flex-col` and `min-h-full`, so the footer should be placed at the bottom of the flex container.
