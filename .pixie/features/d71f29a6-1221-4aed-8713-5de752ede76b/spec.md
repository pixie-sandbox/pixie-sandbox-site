## Outcome

Users can share direct links to specific changelog updates via a single click.

## What was asked for

Adds a 'copy permalink' capability to each entry on the changelog page. Users can click a small, muted button located inline after the entry title to copy a URL containing a slugified anchor ID to their clipboard. The button provides immediate feedback by temporarily changing its label to 'Copied'.

## Acceptance criteria

- **AC1** — given A visitor is viewing the changelog page, when they click the copy button next to an entry titled 'New Feature Released!', then the clipboard contains a URL ending in '#new-feature-released'
- **AC2** — given A visitor has clicked the copy button, when the copy action is successful, then the button label displays 'Copied' and reverts after approximately 2 seconds
- **AC3** — given A screen reader user is navigating the changelog, when they focus on the copy button, then the button provides a clear, accessible description of its purpose

## Components the Architect expected to change

- `components/changelog/ChangelogEntry.tsx` (modify) — Update to include an anchor ID on the title and add the Copy Link button component.
- `__tests__/changelog/ChangelogEntryCopyLink.test.tsx` (new) — New test file to verify anchor ID generation, clipboard copying, and button state transitions.
