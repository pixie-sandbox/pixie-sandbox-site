## Outcome

Users can see the total number of updates recorded on the changelog page at a glance.

## What was asked for

The Sandbox site changelog page will display the total count of all entries found in the `changelog.json` data file. This count will appear prominently at the top of the page, positioned directly beneath the main page heading, using muted text styling to distinguish it from primary headings.

## Acceptance criteria

- **AC1** — given the changelog page is loaded with multiple entries in `changelog.json`, when the page renders, then the system displays the correct count followed by the word 'entries' (e.g., '12 entries') directly under the heading in muted text.
- **AC2** — given the changelog page is loaded with exactly one entry in `changelog.json`, when the page renders, then the system displays '1 entry' directly under the heading in muted text.
- **AC3** — given the changelog page is loaded with zero entries in `changelog.json`, when the page renders, then the system displays '0 entries' directly under the heading in muted text.

## Components the Architect expected to change

- `app/changelog/page.tsx` (modify) — Update the header section to include the total entry count calculation and display logic.
